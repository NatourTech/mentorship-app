# Mentorship SaaS Platform

This is a Laravel-based mentorship platform for connecting mentors and mentees, offering session scheduling, payments, Zoom integration, and more.

> 📦 Based on: [Mentorship SaaS by OriginLabSoft](https://mentorship.originlabsoft.com/docs/)

---

## 📁 Project Setup with XAMPP (Localhost)

These are the steps followed to run the project locally using XAMPP:

### ✅ 1. Install XAMPP

- Download and install [XAMPP](https://www.apachefriends.org/index.html)
- Make sure to start **Apache** and **MySQL** from the XAMPP Control Panel.
